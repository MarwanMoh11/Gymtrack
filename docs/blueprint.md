# **App Name**: GymTrack

## Core Features:

- Workout Display: Displays workout routines for each day of the week in a clear and structured format.
- Workout Logging: Allows users to log completed sets, reps, and weights for each exercise.
- Progress Tracking: Displays a visual progress for workouts
- AI-Powered Recommendation: Offers AI-powered recommendations to adjust weight or reps based on the user's logged performance, acting as a tool for progressive overload.

## Style Guidelines:

- Primary color: Dark gray (#333) for a strong base.
- Secondary color: Light gray (#f0f0f0) for backgrounds and subtle contrasts.
- Accent: Teal (#008080) to highlight interactive elements.
- Clean, sans-serif font for readability and modern look.
- Clear sections for each exercise and set, with ample spacing.
- Subtle transitions for loading and completing exercises.
